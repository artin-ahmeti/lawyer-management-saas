Select trigger styled like a text field; opens a picker sheet on mobile.

Show identifiers with `mono` (matter number, account suffix), UTBMS codes with `code`, and stage colours with `dot`.

```tsx
<Field label="Matter"><Select value="Estate of Harold Bennett" mono="2026-0187" /></Field>
<Field label="Activity"><Select code="L110" value="Fact investigation" /></Field>
```
