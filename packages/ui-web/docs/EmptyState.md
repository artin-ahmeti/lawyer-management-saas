Icon in a tonal circle, a title, one sentence, at most one action.

The sentence says what will appear here and how. `large` uses title-2 for first-run moments.

```tsx
<EmptyState
  icon="clock"
  title="Nothing to review"
  text="Calls, meetings and voice memos you haven't billed will show up here."
/>
```
