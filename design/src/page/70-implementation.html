08 · Implementation

From this page to the codebase

Nothing in the app has been changed yet; the system lives in design/ in the repo. With Cobalt and the name settled, the work is mechanical and lands in this order.

Sync to Claude Design

Run /design-sync, create a project called Clepso, and use design/system as the local directory. Every components/*/preview.html carries the @dsCard marker, so the Design System pane builds its cards on upload. Then generate the remaining H1 screens (calendar, contacts, matter tabs, payments, trust ledger, onboarding) against this system.

Generate the mobile tokens

Extend design/src/build.py to emit packages/ui/src/tokens.ts and packages/ui/tailwind-preset.cjs from tokens.py: colour tokens as light/dark pairs, spacing, radius, sizes, and the type scale as NativeWind fontSize entries. Delete the hand-kept duplicates.

Fonts and theme plumbing

Add @expo-google-fonts/geist, @expo-google-fonts/geist-mono and expo-font; load them in the root layout behind the splash screen. Add a theme provider (system / light / dark / courthouse) that sets NativeWind’s colour scheme and the status bar. Replace every hard-coded hex with a token.

Rebuild the primitives

In apps/mobile/src/components/ui: Button (variants, sizes, icon slot, loading), Field/Input (affixes, states), Pill, Chip, Segmented, Switch/Check, List/Row, Avatar, Section, Card, KpiTile, Banner, Toast, Sheet, Dialog, StageTracker, TimerBar, TabBar, EmptyState, Skeleton. Icons via phosphor-react-native.

Re-cut the navigation

Tabs become Today · Matters · Capture · Calendar · Billing with a custom tab bar (centre Capture button, docked timer bar). Tasks and Time tabs are removed; their content moves into Today, Matter detail, Capture and Billing. Inbox starts as a header icon.

Rebuild the screens against mock hooks

Today, Matters, Matter detail, Capture, Log time, Billing, Invoice, Sign in, then the client-app shell in apps/portal when it is scaffolded. The existing mock hooks keep working; only the presentation changes.

Web

When apps/web is scaffolded, it consumes the same Tailwind preset plus tokens.css, and ports the components as React + Tailwind with identical class vocabularies. Sidebar, top bar, table and drawer are the only new pieces.

09 · Open items

Settled, and what is left

Accent (Cobalt) and the name (Clepso) are decided and applied throughout. Two smaller calls remain; my recommendation is first in each.

1 · Tab bar in H1

Today · Matters · Capture · Calendar · Billing (recommended for H1: “bill from the courthouse”) · or swap Calendar for Inbox now if lead response ships earlier than planned.

2 · Mark

The placeholder mark is a cobalt tile with a “C” arc, set next to a tight Geist wordmark. It is deliberately simple and can ship in the staff app; a considered logo should replace it before the client app or any marketing goes out.
