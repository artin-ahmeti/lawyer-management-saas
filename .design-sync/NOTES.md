# design-sync notes — Clepso (@lawfirm/ui-web)

- The synced package is `packages/ui-web`: thin React DOM components over the Clepso stylesheet. Its CSS is assembled by `scripts/build-css.mjs` from `design/system/tokens.css` + `design/system/components/bundle.css` (both generated by `python3 design/src/build.py` from `design/src`). Change styles in `design/src`, rebuild the design system, then rebuild the package.
- Fonts (Geist, Geist Mono) load from Google Fonts via an `@import` at the top of `dist/clepso.css`; nothing is self-hosted. `runtimeFontPrefixes: ["Geist"]` suppresses `[FONT_MISSING]`.
- The mobile app (`apps/mobile`) is React Native and is not part of the sync; `apps/web` / `apps/portal` are not scaffolded yet. This package is the seed of the web component library.
- pnpm uses `node-linker=hoisted`; `react`/`react-dom` resolve from `packages/ui-web/node_modules` (devDependencies) — pass that as `--node-modules`.
- `cfg.provider = { component: "ClepsoRoot" }` wraps every preview in the root (light theme, mobile density). Previews of web-density components wrap their content in `<div className="cl-web">`; ClepsoRoot's own preview nests a second root to show `theme="dark"` and `density="web"`.
- Wide components carry `cardMode: "column"` overrides (Table, Toolbar, AppShell, BrowserFrame, PhoneFrame, Sidebar, TopBar, PageHeader, TabBar, TimerBar, Drawer, Breadcrumbs, ScreenHeader, NavBar, Sheet, Scrim, Form) so every export keeps full card width.
- `packages/ui-web/docs/<Name>.md` (frontmatter `category` = pane group) is what becomes each `.prompt.md`; keep exactly one per exported component, with a JSX example. `guidelinesGlob` points at the brand book `design/system/README.md`.
- Component source files hold several components each (`Controls.tsx`, `Fields.tsx`, …), so only 6 of 81 are "src-matched"; that only affects sibling-doc lookup, which `docsDir` covers.

## Preview authoring learnings (folded from the first-sync wave)

- Stories are captured one at a time at a 900×700 viewport with 24px body padding; keep each export within ~850×650. Frames need a bigger viewport: `PhoneFrame` `480x940`, `BrowserFrame` `1340x920` (set in `overrides`).
- Mobile compositions sit in `<div style={{ maxWidth: 358 }}>`; web-density ones in `<div className="cl-web">`. `ChipGroup` and `SegmentedControl scroll` are nowrap scroll rows, so static captures clip past the edge — keep chip rows short.
- `ListRow` truncates titles as soon as a trailing column exists; keep subtitles under ~30 characters at 358px. `Stack` blockifies inline children (pass `alignItems: 'flex-start'` when stacking pills). `SectionHeader` carries its own margins; don't stack several inside `cl-stack`.
- Controlled inputs without `onChange` warn in React; previews use `defaultValue`.
- CSS/component fixes made during the wave: `.cl-swipe` row/action flex (actions collapsed to slivers), `Textarea minHeight` now applied to the textarea, `.cl-avatar-stack` overlap for `xs`, `.cl-card--ink` subtitle/cents contrast, `:disabled` styling for switch/check/chip. `Table kind: 'foot'` needs a full-length `cells` array (no colspan).
- Skipped states (interaction-only): hover/pressed on all controls, skeleton shimmer, swipe drag, Select picker open, Form submission. `Card tone="danger"` not previewed.
- Six-stage `StageTracker` labels ellipsize at 358px exactly as the design's own previews do — legitimate.

## Known render warns

- `[FONT_REMOTE] "SF Pro Text" (--font-sans)` — a fallback family inside the Geist stack; Geist itself loads from the Google Fonts `@import` at the top of `dist/clepso.css`. Legitimate.
- `[DTS_STYLE_SYSTEM] filtering @types/react props` — informational; HTML attribute bags are filtered from `<Name>Props`.

## Re-sync risks

- Renders need network access for Google Fonts; offline, cards fall back to the system font and grading is invalid.
- Styles flow `design/src/*.css` → `python3 design/src/build.py` → `design/system/**` → `pnpm --filter @lawfirm/ui-web build` → `dist/clepso.css`. Skipping the first step ships stale CSS; skipping the second ships a stale bundle (the converter needs `dist/`).
- Playwright 1.63 + chromium live only in `~/Library/Caches/ms-playwright` (macOS) and `.ds-sync/node_modules` (both gitignored); a fresh clone re-installs them (`cd .ds-sync && npm i playwright && npx playwright install chromium`).
- The mobile app does not consume `@lawfirm/ui-web`; if the web app later changes component APIs, re-author the affected previews (grades follow the `.tsx`).
